Навык агента · GitHub Action

token-meter

Знайте свои токены до сжатия.

Живой счётчик токенов для Claude Code, только для чтения: насколько заполнен контекст каждой сессии, сколько ходов осталось до автосжатия, предупреждение об остывшем кэше и серверы MCP и навыки, которые вы никогда не вызываете. Режим советов предлагает, что урезать и улучшить: сжать, начать заново, сократить, планировать и строить на разных моделях, локальная модель, новый навык. Работает офлайн: без телеметрии, без хуков, без правки настроек.

Новое в v0.5.0: сколько стоит при каждом вызове каждый CLAUDE.md, правило и заголовок навыка, счётчик в строке состояния и токены, которые экономит каждое сокращение.
