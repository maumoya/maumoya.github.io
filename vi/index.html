Agent skill · GitHub Action

token-meter

Nắm rõ token trước khi compact.

Đồng hồ đo token trực tiếp, chỉ đọc cho Claude Code: context của mỗi phiên đã đầy bao nhiêu, còn bao nhiêu lượt trước khi tự động compact, cảnh báo cache nguội, và các MCP server cùng skill bạn không bao giờ gọi. Chế độ tư vấn đề xuất nên cắt gì và cải thiện gì: compact, bắt đầu phiên mới, rút gọn, lập kế hoạch và xây dựng trên các mô hình khác nhau, mô hình cục bộ, skill mới. Chạy ngoại tuyến: không telemetry, không hook, không sửa cài đặt.
