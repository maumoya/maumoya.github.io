token-meter

Claude Code 用のライブ・読み取り専用トークンメーター：各セッションのコンテキストの埋まり具合、自動圧縮までの残りターン数、キャッシュが冷えた警告、一度も呼ばれない MCP サーバーとスキル。アドバイスモードは削るべき点と改善点を提案します：圧縮、新規セッション、整理、計画と構築で別モデル、ローカルモデル、新しいスキル。オフラインで動作：テレメトリなし、フックなし、設定変更なし。
