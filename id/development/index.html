Skill agen · GitHub Action

token-meter

Kenali token Anda sebelum compact.

Meteran token live dan read-only untuk Claude Code: seberapa penuh konteks tiap sesi, sisa giliran sebelum auto-compact, peringatan cache dingin, serta server MCP dan skill yang tidak pernah Anda panggil. Mode saran mengusulkan apa yang perlu dipangkas dan ditingkatkan: compact, mulai dari awal, rampingkan, rencanakan dan bangun dengan model berbeda, model lokal, skill baru. Berjalan offline: tanpa telemetri, tanpa hook, tanpa mengubah pengaturan.

Baru di v0.5.0: biaya setiap CLAUDE.md, rule, dan header skill di setiap panggilan, meteran di status line, dan token yang dihemat tiap pemangkasan.
