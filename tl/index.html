Agent skill · GitHub Action

token-meter

Alamin ang tokens mo bago mag-compact.

Isang live at read-only na token meter para sa Claude Code: gaano na kapuno ang context ng bawat session, ilang turn pa bago ang auto-compact, babala kapag cold ang cache, at ang mga MCP server at skill na hindi mo kailanman ginagamit. Ang advise mode ay nagmumungkahi ng babawasan at pagagandahin: compact, magsimula ulit, mag-trim, magplano at bumuo sa magkaibang model, local model, bagong skill. Tumatakbo ito offline: walang telemetry, walang hooks, walang binabagong settings.

Bago sa v0.5.0: ang gastos ng bawat CLAUDE.md, rule at skill header sa bawat call, isang status line meter, at ang tokens na natitipid ng bawat bawas.
