truly-done

Il dit que c'est fait. Truly Done vérifie.

Une skill pour Claude Code qui prouve qu'un changement fonctionne dans l'application en cours d'exécution. Skill d'agent · GitHub Action

token-meter

Connaissez vos tokens avant de compacter.

Un compteur de tokens en direct et en lecture seule pour Claude Code : le remplissage du contexte de chaque session, les tours restants avant la compaction automatique, une alerte de cache froid et les serveurs MCP et skills que vous n'appelez jamais. Le mode conseil propose quoi couper et améliorer : compacter, repartir de zéro, alléger, planifier et construire avec des modèles différents, un modèle local, une nouvelle skill. Nouveau dans v0.5.0 : le coût à chaque appel de chaque CLAUDE.md, règle et en-tête de skill, un compteur dans la ligne d'état et les tokens que chaque coupe fait gagner.
